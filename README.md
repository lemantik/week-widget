# Виджет «Неделя»

Скользящее окно из 7 дней, начиная с сегодня. Ближние дни шире и крупнее,
дальние — уже и мельче. Данные берутся из системного календаря Android,
куда Google Calendar синхронизируется сам.

## Как собрать

**Готовый APK** — в [Releases](../../releases): GitHub Actions собирает и публикует его
на каждый push в `main`. Новые версии ставятся поверх старых (одинаковый ключ подписи,
`versionCode` = номер запуска workflow).

**Локально:** откройте папку в Android Studio или выполните `./gradlew assembleDebug`
(нужны JDK 17 и Android SDK). Release-сборка без ключа подписывается debug-ключом.

На телефоне: открыть приложение «Неделя», выдать доступ к календарю,
добавить виджет «Неделя» на главный экран.

### Подпись в CI

Workflow `.github/workflows/release.yml` берёт ключ из секретов репозитория
(Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | keystore (`.jks`), закодированный в base64: `base64 -w0 release.jks` |
| `SIGNING_STORE_PASSWORD` | пароль keystore |
| `SIGNING_KEY_ALIAS` | alias ключа |
| `SIGNING_KEY_PASSWORD` | пароль ключа |

Без секретов сборка в `main` падает — чтобы не опубликовать APK с чужой подписью.
На остальных ветках APK собирается как проверка и лежит в артефактах запуска.
Сам keystore в репозиторий не коммитится (`*.jks` в `.gitignore`) — храните его копию отдельно.

## Что где

| Файл | Что делает |
|---|---|
| `CalendarRepository.kt` | Запрос событий на 7 дней, многодневные и «весь день» |
| `WeekWidget.kt` | Внешний вид; **настройки ширины и шрифтов — в начале файла** |
| `WidgetUpdater.kt` | Загружает данные и перерисовывает виджет |
| `Scheduling.kt` | Обновление в полночь, при изменении календаря и раз в час |
| `Receivers.kt` | Жизненный цикл виджета, смена часового пояса |
| `MainActivity.kt` | Экран с запросом доступа к календарю |

## Поведение

- Тап по событию открывает его в Google Calendar, тап по дню — календарь на этом дне.
- Пустой день — колонка только с заголовком.
- Не влезло по высоте — внизу «+N».
- Выходные подсвечены цветом ошибки темы; цвета виджета берутся из системной темы (Android 12+).

## Ограничения

- В Glance не больше 10 элементов в одной колонке, поэтому максимум 7 событий на день.
- Скругления углов работают на Android 12+.
- WorkManager в режиме Doze может сдвинуть полночное обновление на несколько минут;
  на этот случай виджет всё равно не показывает прошедшие дни.
